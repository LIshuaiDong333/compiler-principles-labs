# Compiler Principles Labs

Java compiler experiments covering lexical analysis, syntax analysis, intermediate representation, and assembly generation.

- `template`: original unpacked project snapshot.
- `lab1/template`: unpacked lexical-analysis experiment.
- `lab2/template`, `lab3/template`, `lab4/template`: source snapshots recovered from the corresponding experiment archives.
- `lab2/workbench`: text grammar, input program, and HTML analysis output.

Each Java snapshot has its own `src`, `data`, and `scripts` directories. Use the Java version supported by the supplied sources. Result-checking scripts may require Python and a separately installed RARS JAR. Binary compiler-workbench state, compiled classes, and bundled executables are excluded.

## Publication scope

This is a reviewed export of local coursework. Word/PDF reports, archives, credentials, personal submission names, build output, and old Git history are excluded. Original source bytes and encodings are preserved except for the anonymous CSAPP identity placeholders. Upstream attribution and license files are retained where supplied.

The root `.gitignore` uses an explicit file allowlist. Review new files for personal information before adding them. Some experiments depend on their original course framework or external development tools.
